# 课前检查清单（T-30 分钟）

> 打印这一页。逐项打勾，别凭记忆。

## 一、程序

- [ ] 版本号确认：右下角 `v0.5.6`（或当前版本）
- [ ] 面板地址端口是 **18080**（`http://192.168.x.x:18080/j/...`）
- [ ] 二维码显示正常，不是空白
- [ ] 「在线人数」随手机进入会变（先用自己的手机试）

## 二、用自己的手机走一遍（最重要）

- [ ] 手机连现场 WiFi，扫码，**30 秒内**能打开页面
- [ ] 发一条文字，讲师机屏幕上出现
- [ ] 发一张图片，显示正常
- [ ] 断网重连，还能继续发

> 这一步失败，今天就别指望学员成功。先解决再说。

## 三、投屏

- [ ] 投屏引导页能打开（快捷键 `J`）
- [ ] 投影上二维码清晰可扫（手机举起来试一下距离）
- [ ] 备用：链接文字能看清（有人扫码失败时手动输）

## 四、网络兜底

- [ ] 讲师机有备用网络（手机热点 / 5G 网卡），并**确认可用**
- [ ] 远程模式令牌已配好（如果打算用），且点开能到「固定隧道已连接」
- [ ] 知道今天用的是哪种：□ 全部局域网　□ 全部远程（不混用）

## 五、记录准备

- [ ] `docs/field-trial/_template.md` 复制好，改成今天的文件名
- [ ] 手机/纸笔准备好记事件（或者用手机备忘录）
- [ ] 计时起点记下：第一张幻灯片开始的时间

## 六、开场话术（30 秒）

> "屏幕上和投影上都有二维码，手机扫一下就能发弹幕。
> 打不开的先连 `Training-5G`，密码 `danmu2026`，再扫一次。
> 还打不开举手，我过去看。"

把这三句写在手边，别临场组织语言。
