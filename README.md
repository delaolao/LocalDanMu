# 培训弹幕 v0.1.3（本地版）

线下培训用的弹幕系统：讲师在自己电脑上开一个窗口，观众扫码进入网页发文字/图片，内容实时飘在 PPT 上方；需要看整体意见分布时，一键切到「词云」大屏。

- **不遮挡**：弹幕层透明、置顶、鼠标点击穿透，讲师照常操作 PPT。
- **不安装**：观众零安装、零注册，手机扫码即用（纯 H5）。
- **私密**：所有消息只在讲师电脑内存里，不经过任何第三方服务器，默认不落盘。
- **两种看法**：滚动弹幕看单条，词云看比例；错过的可以回看、可以重播。
- **有护栏**：手机号/广告/脏话默认拦截，可自定义词表或导入。

只支持 Windows。界面风格沿用 MyPassword 的深墨绿 + 薄荷绿。

> 想了解代码结构、模块关系和各处"为什么这么写"，看 **[docs/architecture.md](docs/architecture.md)**（实现文档，含需求对照表与技术路线讨论）。

## 一、快速开始

### 1. 直接运行（开发机）

```bash
npm install
npm start
```

### 2. 打包给讲师用

```bash
npm run dist        # 只打包，不建 zip
npm run dist:cn     # 国内网络用这个：走 npmmirror 镜像，并且顺带打好绿色版 zip
```

产物（三种形态，按需分发）：

| 文件 | 形态 | 说明 |
| --- | --- | --- |
| `dist\LocalDanMu-Setup-0.1.3.exe` | 安装版 | 双击安装，开始菜单有快捷方式，装到 `%LOCALAPPDATA%` |
| `dist\LocalDanMu-Portable-0.1.3.exe` | 单文件便携版 | 一个 exe，双击即用，不需要安装；每次启动会解压到临时目录，启动稍慢 |
| `dist\LocalDanMu-0.1.3-win-x64.zip` | 绿色解压版 | 解压到任意文件夹，双击里面的 `LocalDanMu.exe`；启动最快，推荐 U 盘/临时电脑用 |

三种形态功能完全一样，只是数据目录不同（见下）。

首次打包需要联网下载 Electron 和 NSIS 工具链（约 150MB）。国内直连 GitHub 经常超时，`npm run dist:cn` 会自动切到 npmmirror 镜像。

> 未做代码签名，首次运行 Windows SmartScreen 可能提示"未知发布者"，点"更多信息 → 仍要运行"。

### 3. 绿色版（免安装）说明

- 解压后双击 `LocalDanMu.exe` 即可，不写注册表、不装服务、不需要管理员权限。
- 目录里的 `portable.txt` 是便携标记：程序看到它就把 `settings.json` 写到 exe 旁边，不往 `%APPDATA%` 里塞东西。
- 换电脑 / 换 U 盘：把整个文件夹拷走就行，设置跟着走。
- 卸载：直接删文件夹。
- 如果解压到了 `Program Files` 这类不可写目录，程序会自动退回 `%APPDATA%\local-danmu` 存配置，功能不受影响。

## 二、现场使用流程

1. 打开程序，主面板会显示二维码和链接（`http://192.168.x.x:8080/j/<房间号>/`）。
2. 在「设置与网络」里填上现场 WiFi 的名称和密码（只需要填一次，之后会记住）。
3. 开场点「投屏引导页」（或 `Ctrl+Alt+J`）：投影上会出现一个大二维码 + 链接 + WiFi 名称和密码的页面，学员照着连 WiFi、扫码即可。讲完按 `Esc` 关掉，切回 PPT。
4. 弹幕会出现在**选中的显示器**上，压在 PPT 之上，鼠标可以正常点 PPT。
5. **点一下弹幕里的图片**：指针停在图片上会让滚动暂停并描一圈薄荷色，点一下居中放大；再点任意位置（或按 `Ctrl+Alt+G`）关闭并继续滚动。
6. **需要看整体意见时**切到「词云弹幕」（面板按钮或 `Ctrl+Alt+K`）：左边按出现次数排字号并带 `×N`，右边是实时消息流，可往回翻。
7. 控制面板的「最近弹幕」一直保留最近 200 条，点每行右边的 `↻` 可以把这条重新推上屏（错过、或者想再强调一次）。
8. 讲完点「结束培训」：断开所有手机连接，清空内存里的消息，然后可以「开始新一场」（换新房间号）。

### 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+Alt+空格` | 暂停 / 恢复弹幕（暂停时新消息会攒着，恢复后继续出现） |
| `Ctrl+Alt+X` | 清屏（不删数据，只是清掉屏幕上的） |
| `Ctrl+Alt+J` | 打开 / 关闭投屏引导页（二维码 + WiFi） |
| `Ctrl+Alt+K` | 在「滚动弹幕 / 词云」之间切换 |
| `Ctrl+Alt+G` | 关闭图片大图，恢复滚动（兜底） |
| `Ctrl+Alt+M` | 显示 / 隐藏控制面板 |

弹幕层是点击穿透的，点不到；托盘图标和控制面板都藏起来时，用快捷键找回来。

## 三、现场排障（重要）

这类系统在现场 90% 的问题都是网络，程序本身没问题。按顺序检查：

### 1. 手机和电脑是不是同一个 WiFi？

不是同一个网段一定连不上。电脑开了 VPN / 分身网卡时，注意选对网卡。

### 2. 是不是选错了网卡？

程序会自动挑一个最可能的地址（优先有默认路由、非虚拟网卡），但装了 Hyper-V、WSL、VMware、Tailscale、VPN 的机器可能有 5、6 个网卡。

**症状**：二维码里的 IP 是 `192.168.50.1`、`172.x`、`100.64.x.x` 之类，手机打不开。

**处理**：控制面板 → 设置与网络 → 「网卡」下拉，换成 `Wi-Fi` 或 `以太网` 那个，二维码会自动刷新。

### 3. Windows 网络是不是「公用」？

公用网络下 Windows 防火墙默认拦截入站连接，手机就会一直"打不开"。

**处理**：设置 → 网络和 Internet → 属性 → 网络配置文件改为「专用」。程序检测到公用网络时会在顶部显示黄色提示。

### 4. 场地 WiFi 开了「设备隔离」

酒店、会议中心的访客 WiFi 经常开启 AP isolation（客户端隔离），同一 WiFi 下的设备互相看不见。这种网络怎么设置都没用。

**处理**：用电脑开移动热点（设置 → 网络和 Internet → 移动热点），让手机连电脑的热点，再点「重新检测」。

### 5. 防火墙规则

首次运行时 Windows 会弹窗询问是否允许，**必须勾选"专用网络"并允许**。如果误点了取消：控制面板 → 设置与网络 → 「打开网络设置」→ Windows 防火墙 → 允许应用通过防火墙 → 找到本程序勾上。

打包后是独立的 exe，开发模式放行的是 `node.exe`，两者规则不通用。

### 6. 微信里打不开 / 发不出去

微信内置浏览器（X5 / WKWebView）对局域网 HTTP 一般没问题，但首次打开可能提示"非官方网页"，点继续访问即可。如果一直白屏，改用手机自带浏览器扫码。

### 7. 手机提示"WiFi 无法上网"

电脑没连外网时，手机系统会认为这个 WiFi 有问题：iOS 会弹窗并可能切到流量，Android 会提示"此网络无法访问互联网"。

**处理**：选择"保持连接"/"继续使用此 WiFi"，不要让它切到移动数据——切走就连不上电脑了。

## 四、实现要点

### 单端口

HTTP 和 WebSocket 共用一个端口（8080 起，被占用就往后找 20 个，再不行交给系统分配）。二维码里只有一个地址，防火墙也只涉及一条规则。

### 房间口令

每场随机生成 8 位房间号，链接是 `/j/<房间号>`。口令不对：

- 页面返回 403「链接已失效」；
- WebSocket 升级请求直接 401 断开。

所以同一局域网里没扫到二维码的人也发不了消息。房间号每场都换。

### 限流（三道）

1. 单人间隔：默认 5 秒一条（面板可改 3/5/8/10/15 秒）；
2. 单 IP 令牌桶：0.8 条/秒，突发 8 条（防止有人清缓存绕过）；
3. 全局：4 条/秒，突发 12 条（保护大屏不被刷爆）。

超限返回 `rate_limited` 和 `retryAfter`，手机端显示"发送太快了，休息一下"并倒计时。

### 消息校验

- 文字：去控制字符、零宽字符、方向覆写符（防止伪装），按码点计长度（emoji 算 1 个），上限 100；
- 图片：只接受 `data:image/(png|jpeg|webp|gif);base64,...`，**拒绝 SVG**（SVG 里能塞脚本），base64 长度上限 900KB；
- WebSocket 层 `maxPayload` 2MB，超了直接断连接。

### 弹幕轨道

`src/renderer/danmaku/layout.js` 把可用高度切成行，每行记录"什么时候可以再发车"。

关键点：判断条件是**上一条的尾巴完全进入屏幕**（`x + width + gap <= 屏幕宽`），不是等它飞出屏幕——后者会让吞吐掉一半以上。长文本/图片按行高向上取整占多行，要找到连续的空行。

### 滚动速度

速度用「每秒走过屏幕宽度的百分比」表示，默认 **8%**（1080p 投影约 160px/s，一屏约 12 秒），可调 4%～30%。是常量像素速度，不是按字数算时长，所以长弹幕不会比短的跑得快。

> 早期版本默认 25%，两秒扫完一屏，实际没法读，已改。

### 弹幕颜色

手机端有 9 个选项：随机 + 8 个高对比色（白/黄/绿/蓝/粉/橙/紫/青），选完记在手机本地。服务端只接受白名单里的颜色，乱传的会被清成默认白色——避免有人传个深灰上去，在大屏上看不见。

文字始终保留黑色描边，所以不管 PPT 是白底还是深色都能读。

### 最近弹幕与重播

主进程保留最近 200 条，控制面板实时同步成列表（带时间、颜色点、图片占位）。每行右边的 `↻` 会把这条重新推上屏：切回滚动模式、重新飞一次，但**不重复计数、不进历史**。适合"刚才那条没看清"或者"这个观点再强调一下"。

### 词云模式

`Ctrl+Alt+K` 或面板上的分段按钮切换。词云页是一个独立的置顶窗口，铺满投影：左边词云，右边实时消息流，底部版权行。

- **计数口径**：短句（≤12 字）整条当一个词；长句按标点切段；去掉句尾语气词（"太难了" → "太难"）。不做同义词合并，这是已知局限——现场让大家发两三个字最准。
- **布局**：按次数从大到小，用螺旋 + 矩形碰撞放置，纯 Canvas 实现，没引第三方库；词少时自动放大字号，免得大屏太空。
- **窗口**：和弹幕层一样置顶、不抢焦点，并且**点击穿透**——就算盖在 PPT 上，讲师也能点到下面的东西。

### 关键词过滤

分三类，规则优先：

| 类型 | 内容 |
| --- | --- |
| 规则 | 手机号、QQ 号、微信号、网址、"加群/加V/返利/优惠券"等广告话术 |
| 内置脏话 | 约 50 条通用辱骂词（英文另算），不含政治词 |
| 自定义 | 讲师自己加，支持导入 txt（一行一个），只存本机 |

匹配用前缀树（DFA）；匹配前先做归一化：全角转半角、去零宽字符、去掉空格和符号。所以"傻 逼""傻*逼""ＦＵＣＫ"都能拦住。

三档：命中即拦截（默认）/ 仅标记（照常上屏，列表里标黄）/ 关闭。被拦截的消息**不占用发送额度**，手机端只提示"内容不合适，换个说法"，不回显命中词（避免被用来试探规则）。

> 关于词库：中文互联网上的"敏感词库"绝大多数是政治审查表，不适合内置；这个产品只做培训现场真正会出事的三类，需要更大词表可以自己导入。

### 透明置顶穿透窗口

- 不用 `fullscreen: true`（Windows 上透明 + 全屏经常黑屏），改成按目标显示器 `bounds` 定位的无边框窗口；
- `transparent: true` + `frame: false` + `hasShadow: false` + `roundedCorners: false`；
- `focusable: false` + `showInactive()`：显示窗口但不抢 PPT 的键盘焦点；
- `setIgnoreMouseEvents(true, { forward: true })`：点击穿透；
- `backgroundThrottling: false`：不加这个，窗口失焦时 `requestAnimationFrame` 会被节流，弹幕卡成幻灯片；
- 每 6 秒 + 每次窗口获得焦点时重新 `moveTop()`：PPT 进入放映会打乱 z-order。

### 显示器选择

培训常见「笔记本 + 投影扩展」，所以默认投到主屏，可在设置里切换。切换时直接 `setBounds` 到目标显示器的 `bounds`；显示器拔掉会自动回退到主屏。

### 二维码

用 `qrcode` 在本地生成 data URL（不联网），内容就是 `http://<局域网IP>:<端口>/j/<房间号>`，720×720 存成 base64 交给界面显示。IP 每 15 秒重算一次，变了就重画二维码——中途换 WiFi、DHCP 续租换 IP 都能跟上。

### 投屏引导页

一个独立的置顶窗口，铺满选中的显示器，内容是「大二维码 + 链接 + 现场 WiFi 名称/密码 + 在线人数」。专门解决"开场时怎么让大家连上 WiFi 再扫码"这件事——把信息放大投出来，比口头念一遍靠谱。

- 按 `Esc`、点右上角 ✕、或再按一次 `Ctrl+Alt+J` 关闭。
- 关掉后会回到 PPT，弹幕层仍然在。
- WiFi 信息只存在本地配置里（`settings.json`），不发给任何地方；不填就不显示那一块。

### 弹幕图片点击放大

弹幕层平时是点击穿透的，但鼠标移到**图片**上时会临时接管鼠标（`setIgnoreMouseEvents(false)`），点一下就能暂停滚动并居中放大；点任意位置恢复。文字弹幕不会触发这个行为，所以不会影响讲师操作 PPT。

实现要点：`setIgnoreMouseEvents(true, { forward: true })` 让窗口在穿透状态下仍能收到 `mousemove`，据此做命中测试，命中图片才切换成可点击；大图模式下整屏接管，关闭后再切回穿透。

### 深色 / 浅色 / 跟随系统

- 讲师端：设置里三选一，立即生效并记住；「跟随系统」时跟着 Windows 的深浅色走（`nativeTheme` + `prefers-color-scheme`）。
- 学员端：右上角小按钮循环切换（跟随系统 → 深色 → 浅色），存在手机本地，每台手机各管各的。页面 `<head>` 里有一段同步脚本先定主题，避免浅色用户看到一瞬间的黑屏。

### 不落盘

- 消息只在主进程内存里（文本最多 300 条、图片最多 20 张，超出丢最旧的）；
- 分享给渲染进程的是内存对象，不写文件；
- Chromium 的缓存/存储目录被重定向到系统临时目录，退出时删除；
- 只有「导出本次记录」会写盘，路径由讲师选，导出后界面会显示完整路径。

## 六、开发命令

```bash
npm test        # 服务端 + 轨道 + 过滤 + 词云 四套测试
npm run smoke   # 启动 Electron 自检：截图 + 端到端 + 词云 + 生命周期
npm run dist    # 打包 Windows 安装包
```

`npm run smoke` 会跑一遍完整自检并把截图写到 `scripts/out/`：`control.png`、`control-light.png`、`control-settings.png`、`control-log.png`、`danmaku.png`、`danmaku-modal.png`、`cloud.png`、`join.png`、`viewer-dark.png`、`viewer-light.png`，结果在 `smoke-result.json`。

> 如果终端里出现 `ELECTRON_RUN_AS_NODE=1`，Electron 会退化成普通 Node 运行。启动前清掉这个环境变量：`Remove-Item Env:ELECTRON_RUN_AS_NODE`。

## 七、已知限制

- 只支持 Windows；只支持单实例（第二次启动会把已有窗口调出来）。
- 消息**不经过人工审核**（按需求确定），只有关键词过滤 + 撤回手段：暂停、清屏、结束。现场建议提前说明规则。
- 词云不做同义词合并，「太难了」和「太难」算两个词（已去掉句尾语气词，能合并一部分）。
- 过滤词表以规则和通用脏话为主，不内置政治类词库；漏网的可以自己加词或导入。
- 单条文字上限 100 字；超长内容在屏幕上按屏幕宽度截断加省略号（不换行）。
- 图片统一转成 JPEG 发送，GIF 只保留首帧（浏览器 `drawImage` 取当前帧，不保证是第 1 帧）。
- 鼠标停留在图片上时会临时接管点击，那一小块区域点不到 PPT；移开即恢复。
- 投屏引导页会把 WiFi 密码显示在大屏上——这是本意，但请确认现场允许公开该密码。
- 传输是明文 HTTP/WS，仅限可信局域网。不要开公网隧道直接暴露，若必须远程访问，请自己加一层 TLS 反向代理。
- 结束培训前没导出，数据就没了（这是设计目标，不是 bug）。
