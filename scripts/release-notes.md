## 培训弹幕 v0.1.2

线下培训用的局域网弹幕系统：讲师电脑本地运行，观众扫码即用，消息不出局域网。

### 本次更新

- **加 GitHub 入口**：控制面板页脚右下角多了一个 GitHub 胶囊按钮，点一下用默认浏览器打开仓库主页。
- 图片大图点不开的问题在 v0.1.1 已修（主进程轮询左键触发，不依赖网页 click 事件）。

### 包含功能

- 透明置顶弹幕层：点击穿透、悬停冻结、图片点击放大
- 词云模式：短句聚合 + 螺旋布局，右侧可回溯消息流
- 投屏引导页：大二维码 + 现场 WiFi 账密
- 关键词过滤：联系方式 / 广告 / 脏话规则 + 自定义词表导入
- 深色 / 浅色 / 跟随系统
- 置顶加固：WPS / PowerPoint 放映时弹幕仍在上层

### 安装

下载 `LocalDanMu-Setup-0.1.2.exe` 双击安装。未做代码签名，SmartScreen 提示时选「更多信息 → 仍要运行」。

三种打包形态，功能完全一样，按需选择：

| 文件 | 形态 | 说明 |
| --- | --- | --- |
| `LocalDanMu-Setup-0.1.2.exe` | 安装版 | 双击安装，开始菜单有快捷方式 |
| `LocalDanMu-Portable-0.1.2.exe` | 单文件便携版 | 一个 exe，双击即用，不写注册表；启动时会解压到临时目录，首次稍慢 |
| `LocalDanMu-0.1.2-win-x64.zip` | 绿色解压版 | 解压到任意文件夹，双击 `LocalDanMu.exe`；启动最快，推荐放 U 盘或临时电脑 |

> 绿色版目录里的 `portable.txt` 是便携标记：程序会把 `settings.json` 写在 exe 旁边，不往 `%APPDATA%` 塞东西；整个文件夹拷走即可迁移。

### 首次使用

1. 手机与电脑连同一个 WiFi
2. 手机打不开：把 Windows 网络设为「专用」，或用面板上的「打开网络设置」
3. 场地 WiFi 若开了设备隔离，改用电脑开热点

> 消息只存在讲师电脑内存里，不落盘、不联网；结束培训即清空。
